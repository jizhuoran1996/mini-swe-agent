# BUILDv1-C02 · Agent 提示模板

Builder 在采集前补入冻结的 source/config/test manifest、可见输入路径、可用工具链和资源预算。初始请求与可选后续请求按真实依赖分阶段提供。

## 初始请求

为无显示器的媒体 worker 构建可安装 SDK、插件和工具，提供图像序列与音频文件处理能力，并用新编译的应用证明插件发现和管线执行正常。

### 提供的环境

- 已冻结的目标源码、声明的离线依赖和工具链；目标工程没有预编译产物、对象文件或对象缓存。
- SRC_ROOT、BUILD_ROOT、INSTALL_ROOT、ARTIFACT_ROOT 为实例内独立路径；默认完整干净构建。

### 工程范围

GStreamer core SDK、CPU base/good 媒体插件及 gst-launch/gst-inspect；不构建设备采集、GUI、PTP 特权 helper 或 GPU 插件。

### 工作要求

- 显式启用目标插件，禁止根据某个宿主偶然拥有的库改变功能范围。
- 构建 core/base/good 和相应测试，安装工具、SDK、plugin scanner 与所需插件。

### 交付

- SDK、工具与插件安装包
- 功能和插件依赖清单
- Meson 测试结果
- 独立 C consumer 与媒体结果

请使用提供的源码和依赖，在任务范围内真实构建并保存交付物。按照冻结的测试规格运行测试，保留实际结果、失败与日志。不得用预装同名软件、发布版二进制或空测试替代要求的构建和验证。允许使用官方构建工具与项目脚本，不限制解决过程的工具调用数量。

## 可选后续请求

收到另一段音频和图像序列，用同一 SDK 增加一条组合管线并交付输出，保留已有插件状态。

如启用增量场景，builder 另外提供该任务卡指定并完成绑定的配置变化/补丁及验收要求；它仍属于同一个任务 ID。
