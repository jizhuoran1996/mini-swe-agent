# BUILDv1-D09 · Agent 提示模板

Builder 在采集前补入冻结的 source/config/test manifest、可见输入路径、可用工具链和资源预算。初始请求与可选后续请求按真实依赖分阶段提供。

## 初始请求

为本地 Web 应用交付一个从源码构建、支持 TLS 和反向代理的 NGINX 包，运行官方测试，并让外部于源码树的测试客户端验证静态文件和代理行为。

### 提供的环境

- 固定版本的完整源代码、声明的子模块和测试数据已预置；目标项目的对象文件、已编译库、测试结果和安装目录为空。
- 编译器、引导工具及第三方依赖来源与版本写入输入清单；依赖缓存和本任务产物缓存分别管理。

### 工程范围

HTTP/HTTPS reverse proxy、静态文件和 SSI；不包含 HTTP/3、特权端口或远程生产部署。

### 工作要求

- 配置私有 prefix，编译 HTTP SSL 与常规代理/SSI 模块；预置 PCRE、zlib、OpenSSL。
- 将官方 nginx-tests 指向本轮安装二进制，执行明确的三个 TAP 文件。
- 从打包目录启动普通用户 NGINX 和本地 fixture 上游，校验 TLS、状态码、响应体及配置重载。

### 交付

- NGINX 私有安装归档与 nginx -V 配置清单
- 官方 TAP 日志和文件/案例计数
- 消费者配置、响应摘要和 reload 验证报告

请使用提供的源码和依赖，在任务范围内真实构建并保存交付物。按照冻结的测试规格运行测试，保留实际结果、失败与日志。不得用预装同名软件、发布版二进制或空测试替代要求的构建和验证。允许使用官方构建工具与项目脚本，不限制解决过程的工具调用数量。

## 可选后续请求

为另一个本地路径增加反向代理路由，并通过同一交付包执行配置检查与重载验收。

如启用增量场景，builder 另外提供该任务卡指定并完成绑定的配置变化/补丁及验收要求；它仍属于同一个任务 ID。
