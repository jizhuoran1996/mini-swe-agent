# 当前交付范围与待实施项

本包完成任务来源定位、60个具体任务设计、规模/交付/验收说明、回放与资源准入合同，以及结构校验。它不包含已构建的GPU环境、第三方模型/数据或实机测量。

1. 源代码和模型入口已核查，正式运行前仍需固定不可变revision并取得实际asset哈希。提供的来源版本/配置不等于已在本环境成功运行。
2. 硬件档位是工程计划；峰值显存、耗时、吞吐、GPU利用率、能量和正确率均待实际参考运行，不以模型名或数据大小代替。
3. 数据、权重可能有许可、注册或研究用途条件。按每题来源取得授权和获取配方；ZIP不重分发第三方payload。
4. 个别任务来自历史/retired benchmark，引用其工作负载和语义，不声称当前官方合规成绩。派生子集或改训练起点须单独标记。
5. 大图、完整训练、高分辨率视频和科学数据可能需要多卡/较大host内存或较长执行；它们可由recipe筛选，不要求每台worker运行所有任务。
6. GPU状态快照、offload、MPS/MIG、多卡通信与后端API支持需要单独能力检查。主包不承诺所有CPU sandbox后端都可运行GPU。
7. 生成结果的结构检查不足以证明语义质量；必须实现任务卡所列内容/质量oracle并冻结评价器。应用结果与GPU资源准入分开报告。

实施者应更新任务状态及证据，保留已验证的具体版本、输入和运行结果；不要用日志成功、GPU可见或结构校验通过替代正式运行。
