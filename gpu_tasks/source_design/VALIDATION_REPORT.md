# 本版校验结果

校验范围：任务设计、来源绑定、文件和机器可读记录的一致性。GPU环境、权重、数据与实际执行仍由后续实例构建完成。

- 任务数：60；A–F每组10项。
- 来源记录：119，均有具体URL和检查位置。
- 完整任务卡：60份；agent提示模板：60份。
- 任务ID、canonical goal key、source ID、JSON/JSONL镜像一致性：通过。
- 60条记录的正式规模、验收与GPU条件字段：齐全。
- 不可变资产、运行证据和资源实测：未填充，不被结构校验误记为完成。
- 负向检查：重复任务ID、不存在来源、无证据宣称profiled、design阶段伪造实测值均被拒绝。
- Markdown本地链接、代码围栏与占位标记检查：通过。
- 当前阶段：60条均为design。

交叉审查已修复图像补全的输入捷径、常驻服务的后续请求验收、视频视觉输入预算、SQL质量与基础设施错误的区分、完整天气续报状态、3D时间序列可验范围，以及多GPU聚类的实际API条件。

运行`python3 validate_plan.py --self-check`可重新执行结构检查。它不会安装依赖或调用GPU。后续推进readiness时，校验器要求真实证据文件与内容哈希。
