# GPUv1-C07 · Agent任务提示模板

Builder在实例化时补充可见输入路径、冻结配置、允许的工具和设备预算。初始任务与后续请求分阶段交付；不把本文件中未来请求提前用于模拟再次访问。验证器的隐藏数据不出现在任务环境。

## 初始任务

根据旋律参考和文字要求制作音乐素材库，保留每段素材的参考来源、参数和可播放音频，支持在后续节目中准确选取指定片段。

### 来源和工作范围

facebook/musicgen-melody-large / AudioCraft generate_with_chroma + google/MusicCaps is_balanced_subset

### 交付要求

- music/<asset_id>.wav
- music-assets.jsonl
- listening/index.html

### 必须完成的工作

- 核对每条输入音频片段与源坐标，提取实际旋律条件
- 运行本地 MusicGen 生成新音乐，不直接复制原始音频
- 建立原旋律、描述和成品之间的映射并导出音频库

请在分配的环境中真实完成计算并保存可重载的产物。使用实例清单规定的输入ID、模型和工作量；若出现错误，保留失败项与实际状态。不要用外部模型API、预先生成的答案或重复数据替代规定的GPU工作。允许使用官方CLI和现有工具，无需刻意拆成多次调用。

## 后续请求（依实际依赖单独发出）

按照冻结节目清单使用已交付素材进行配乐编排，返回时间线和实际混音成品；原始生成素材必须保留。

如果后续请求包含新输入，builder在采集前将完整输入集合分为互斥的initial和continuation子集；重复访问另行标记。
