# GPUv1-F01 · Agent任务提示模板

Builder在实例化时补充可见输入路径、冻结配置、允许的工具和设备预算。初始任务与后续请求分阶段交付；不把本文件中未来请求提前用于模拟再次访问。验证器的隐藏数据不出现在任务环境。

## 初始任务

为给定宇宙密度体数据建立四参数回归模型，交付可重新加载的模型、留出集预测和逐参数误差表；后续能够对新的模拟体输出相同语义的参数。

### 来源和工作范围

MLCommons hpc/cosmoflow；cosmoUniverse_2019_05_4parE_tf_v2；128×128×128×4真实模拟裁块。

### 交付要求

- model/及可加载检查点
- predictions.parquet，含source_simulation_id和四个目标
- metrics.json与输入/配置hash

### 必须完成的工作

- 核对四通道含义、目标列及归一化
- 在真实训练数据上完成声明训练阶段并保存权重、优化器和数据进度
- 对留出模拟体计算四参数预测和误差，导出独立推理入口

请在分配的环境中真实完成计算并保存可重载的产物。使用实例清单规定的输入ID、模型和工作量；若出现错误，保留失败项与实际状态。不要用外部模型API、预先生成的答案或重复数据替代规定的GPU工作。允许使用官方CLI和现有工具，无需刻意拆成多次调用。

## 后续请求（依实际依赖单独发出）

重新加载所得模型，为此前未执行推理的同源测试模拟生成预测；保留模型和数据缓存的真实生命周期。

如果后续请求包含新输入，builder在采集前将完整输入集合分为互斥的initial和continuation子集；重复访问另行标记。
