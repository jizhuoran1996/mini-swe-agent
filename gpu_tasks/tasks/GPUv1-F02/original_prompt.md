# GPUv1-F02 · Agent任务提示模板

Builder在实例化时补充可见输入路径、冻结配置、允许的工具和设备预算。初始任务与后续请求分阶段交付；不把本文件中未来请求提前用于模拟再次访问。验证器的隐藏数据不出现在任务环境。

## 初始任务

将给定多变量气候模拟帧转换为背景、大气河流和热带气旋的空间标注，训练并交付可部署的分割模型及留出时段事件目录。

### 来源和工作范围

MLCommons hpc/deepcam；CAM5 All-Hist的train/val/test、stats.h5和DeepCAM参考模型。

### 交付要求

- segmentation-checkpoint/
- masks/和event_catalog.parquet
- 逐类IoU/混淆矩阵及完整输入清单

### 必须完成的工作

- 核对通道统计和类别映射
- 训练源模型并保存可重新加载的checkpoint
- 为留出时段生成逐像素mask，并归纳事件面积与时间索引

请在分配的环境中真实完成计算并保存可重载的产物。使用实例清单规定的输入ID、模型和工作量；若出现错误，保留失败项与实际状态。不要用外部模型API、预先生成的答案或重复数据替代规定的GPU工作。允许使用官方CLI和现有工具，无需刻意拆成多次调用。

## 后续请求（依实际依赖单独发出）

用保存的模型处理新时段，追加事件目录并校验旧时段结果和索引保持一致。

如果后续请求包含新输入，builder在采集前将完整输入集合分为互斥的initial和continuation子集；重复访问另行标记。
